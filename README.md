# 🚀 fozol-pro — ربات فضول‌یاب + مینی‌اپ بله (نسخه ۴.۷)

ادغام کامل ربات [fozol-bot](https://github.com/TheMeg11/fozol-bot) با مینی‌اپ بله در **یک سرویس Railway و یک پروسس**:
تمام امکانات ربات حفظ شده‌اند و مینی‌اپ روی همان دیتابیس کار می‌کند (یک دیتا، دو رابط).

## 🚢 دیپلوی روی Railway (ایمپورت همین ریپو)

1. وارد [Railway](https://railway.app) شوید ← **New Project** ← **Deploy from GitHub repo** ← ریپوی `fozolPro` را انتخاب کنید (دسترسی GitHub App به ریپو بدهید؛ ریپو private است).
2. بعد از اولین بیلد: سرویس ← **Settings** ← **Volumes** ← Mount Path = `/data`.
3. تب **Variables** ← این سه متغیر را بسازید:

   | متغیر | مقدار |
   |---|---|
   | `BOT_TOKEN` | توکن ربات بله |
   | `ADMIN_ID` | شناسهٔ عددی سوپر ادمین |
   | `DB_PATH` | `/data/bot_data.db` |

   (`WEBAPP_URL` لازم نیست — خودکار از `RAILWAY_PUBLIC_DOMAIN` ساخته می‌شود. لیست کامل در [.env.example](.env.example))
4. **Settings** ← **Networking** ← **Generate Domain** ← دامنهٔ عمومی را کپی کنید.
5. در اپ بله به `@BotFather` بروید و آدرس `https://<دامنه>/` را به‌عنوان مینی‌اپ ربات ثبت کنید.

هر push جدید به `main` به‌صورت خودکار روی Railway redeploy می‌شود.

## ✨ جدید در نسخه ۴.۷ (رفع باگ‌ها + ماژولارسازی)

| تغییر | توضیح |
|---|---|
| 🎯 شمارندهٔ کل فضول‌ها | «کل فضول‌ها» حالا تعداد فضول‌های **یکتا** را می‌شمارد (COUNT DISTINCT) — قبلاً کل کلیک‌ها بود |
| 🎯 ماموریت‌ها در مینی‌اپ | منوی دسترسی سریع: VIP با «ماموریت‌ها» جایگزین شد — همان ۳ ماموریت ویژهٔ روز پنل شیشه‌ای (seed یکسان) با نوار پیشرفت زنده و صفحهٔ جزئیات |
| 🚪 اد اجباری واقعی | fail-closed مثل ربات + نرمال‌سازی شناسهٔ کانال (@username/عددی) + لینک دعوت واقعی + رفرش دوره‌ای هر ۵ دقیقه — کانال‌های پنل مینی‌اپ بدون ری‌استارت فعال می‌شوند |
| ⚠️ اخطار به کاربر | دکمهٔ «اخطار به کاربر» در منوی گزینه‌های هر کاربر (پنل شیشه‌ای + مینی‌اپ) — اخطار سوم خودکار مسدود می‌کند |
| 👤 فقط نام برای غیر VIP | کاربر عادی در گزارش‌ها و لیست‌ها فقط **نام** فضول را می‌بیند — بدون شناسه/یوزرنیم/عکس (هم‌راستا در دو رابط) |
| 🎁 پاداش‌ها در مینی‌اپ | جایزه روزانه (استریک + پاداش درصدی) و کد هدیه (لیست کدهای فعال + فعال‌سازی) — هم‌ارز منوی 🎁 ربات |
| 🎡 گردونهٔ هم‌گام | جوایز/وزن‌ها/شاخص روزانه دقیقاً همان ربات؛ فقط VIP (مثل ربات)؛ بدون پاداش دوبرابر |
| 🕳️ تلهٔ اختصاصی VIP-only | مثل ربات: ساخت تله فقط برای VIP با سقف تنظیم زندهٔ vip_max_traps |
| 📢 کانال اطلاع‌رسانی | دکمهٔ @fzxinfo در بخش پشتیبانی/ارتباط (ربات + مینی‌اپ) — هدایت مستقیم به کانال |
| 🔗 حد بیو در کپی لینک | بایو بله ۷۰ کاراکتر است؛ هایپرلینک اصلی ۲۹ کاراکتر می‌گیرد → متن حداکثر ۴۱ کاراکتر؛ از کاراکتر ۴۲م فقط پیام قرمزِ زیرخط‌دار «توی بیو جا نمیشه! کوتاه تر بنویس» زیر کادر |
| 🔥 استریک هم‌گام | باز کردن مینی‌اپ هم زنجیرهٔ روزانه و XP ورود را مثل ربات ادامه می‌دهد (سپر VIP هم اعمال می‌شود) |
| 🧩 ماژولارسازی | main.py از ۱۳.۶k خط به ۱۰.۵k خط؛ Database → `bot_db.py`، ابزارهای خالص → `bot_helpers.py`، رسانهٔ چرخ → `bot_wheel_media.py`، بکاپ/گزارش → `bot_backups.py`، چالش → `bot_challenge.py`؛ سرویس‌های جدید `services/missions.py` و `services/rewards.py` |

## ⚙️ متغیرهای محیطی (Railway → Variables)

| متغیر | ضروری | مقدار |
|---|---|---|
| `BOT_TOKEN` | ✅ | توکن ربات بله |
| `ADMIN_ID` | ✅ | شناسه عددی سوپر ادمین (مثلاً `123456789`) |
| `DB_PATH` | ✅ | `/data/bot_data.db` (روی Volume) |
| `WEBAPP_URL` | ➖ | `https://<دامنهٔ سرویس>` — خالی = خودکار از `RAILWAY_PUBLIC_DOMAIN` |
| `PROVIDER_TOKEN` | ➖ | توکن درگاه (`WALLET-...`) — خالی = خرید غیرفعال |
| `MINIAPP_DEMO` | ➖ | پیش‌فرض `off` |

### Volume
سرویس ← Settings ← Volumes ← Mount Path = **`/data`**

## 📲 ثبت مینی‌اپ در BotFather بله (بعد از دیپلوی)

1. در اپ بله به `@BotFather` بروید و ربات را انتخاب کنید.
2. بخش مینی‌اپ: آدرس `https://<دامنه>/` را به‌عنوان مینی‌اپ اصلی ثبت کنید.
3. دکمهٔ منو را روی همان آدرس با متن «مینی‌اپ» تنظیم کنید (اگر `setChatMenuButton` از API پذیرفته نشود).

## 🩺 تأیید سلامت

- لاگ باید `🚀 ربات @... راه‌اندازی شد (fozol-pro)` و `listening on 0.0.0.0:8080` را نشان دهد.
- `GET /health` → `{"ok":true,"db":true,"bot":true}`
- در بله `/start` بدهید ← دکمهٔ «📱 باز کردن مینی‌اپ» ← ورود بدون خطا.

## 🔐 امنیت

- هیچ توکنی در کد نیست — همه در Variables.
- initData با HMAC-SHA256 سمت سرور اعتبارسنجی می‌شود؛ به user_id کلاینت اعتماد نمی‌شود.
- CSP با frame-ancestors برای `*.bale.ai` (نسخهٔ وب بله با iframe باز می‌کند).
- بعد از اتمام کار، توکن‌های Railway را از Account Settings → Tokens باطل کنید.
